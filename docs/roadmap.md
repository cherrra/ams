- [x] Восстановлена фактическая схема БД
- [x] Зафиксированы баги legacy

## Этап 1 — каркас API ✅
- [x] Монорепо (npm workspaces): `apps/api`, `packages/shared`
- [x] NestJS 12 + Prisma + Swagger + healthcheck
- [x] Prisma-схема под реальную БД

- [x] Профиль: GET/PATCH, удаление аккаунта
- [x] Загрузка аватара и фото авто (multer, лимит размера, MIME)
- [x] Админский список пользователей (`GET /users`, `GET /users/:id`, `DELETE`)
